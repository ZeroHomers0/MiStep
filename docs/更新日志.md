# 更新日志

本页汇总各正式版本的改动、验证范围与发布检查结论。逐版本的原始记录已合并到这里，不再单独保留。

## 当前开发版（未发布）

工作区顶部改为**一步标题栏**：时钟、`One Step` 标题和四个固定按钮（小窗放左、小窗放右、系统设置、放大为全屏并退出工作区），下方是常用应用栏。同时移除了以下功能及其入口：

- 控制中心（Wi-Fi、移动数据、蓝牙、VPN、音量、亮度、机型信息、扫一扫、付款码、乘车码）。
- 原生音乐卡片与歌词。
- 文本剪贴板面板。
- 截图、录屏、手电筒工具栏。
- 微信扫一扫、付款码、乘车码快捷入口。
- 「关于 OneStepLite」与在线捐赠致谢名单。
- 运行日志、问题录制与诊断包导出（设置页不再有「运行日志」入口）。

新增**视频接入**：横屏全屏视频进入时，可选择置顶播放、在主窗内横屏播放，或退出 OneStepLite 恢复全屏播放。视频接入只接管播放器已有的画中画或悬浮视频窗口，不改变应用任务本身的大小和位置。

设置页调整为四组：外观、窗口与操作、视频、锁屏。界面文案统一为「主窗 / 小窗」。

## 1.0.4

版本码 `1000248`，最低安装 Android 14 / API 34，target API 37。

- 新增「无限小窗」：开启后可继续添加副任务，并在副窗列中上下滚动。
- 普通退出工作区后保留已收纳的副任务，再次进入可接着使用。
- 「关于 OneStepLite」新增捐赠致谢名单（该入口已在当前开发版移除）。
- 优化快捷应用栏横向滑动，松手后支持惯性滚动。
- 修复多个副窗同时存在时，未参与主副交换的副窗可能短暂消失。
- 改进从桌面打开已收纳任务时的画面衔接，修复微信小程序有时误切到微信主界面。

验证：正式 APK 通过完整构建、项目离线测试、签名与 16 KB 对齐检查。分项设备测试主要在澎湃 OS 2 / Android 15 的 Redmi Note 11T Pro 上完成；澎湃 OS 4 / Android 17 的 Xiaomi 17 Pro Max 已验证部分候选的安装与加载。正式 APK 未单独安装验收。

## 1.0.3

版本码 `1000199`。

- 新增澎湃 OS 2 支持。
- 新增平板适配：横竖屏布局、独立竖屏小窗、副任务自动补位，竖屏小窗支持双指滑回主区域。
- 新增模块设置页，从「系统设置 → OneStepLite」进入，支持浅色与深色主题。

- 新增「锁屏时保留 OneStepLite」，解锁后恢复原工作区与任务。
- 新增运行日志与问题录制，支持记录锁屏问题并导出诊断包。
- 修复小屏幕控制中心布局、澎湃 OS 3 桌面上滑误退出、指纹动画缩放异常。

验证：Redmi Note 11T Pro（OS 2 / Android 15）验证核心收纳、双向交换、主区物理触摸、正常退出、锁屏保留与恢复；Xiaomi 17 Pro Max（OS 4 / Android 17）验证真实 TOP 点击、指纹动画与验证面板原位；Pad 6S Pro（OS 4 / Android 17）验证横屏多格、独立竖窗、补位交换与双指回主区域。

## 发布检查

每个正式版本在发布前执行同一套检查，结论记录如下：

- **构建**：从完整 Java 与 ARM64 原生源码编译，不复用开发期 class 缓存；Manifest、资源链接与 D8 最低 API 统一，target API 为 37。
- **离线测试**：编译独立 Java 策略测试，执行提取自生产源码的方法回放，再运行模拟 WMS 的任务旋转、层序与最终事务检查。
- **打包**：APK 签名、16 KB 页对齐、模块入口与原生库包装检查；构建脚本把项目许可、第三方说明及全部上游许可原文放入 `assets/onesteplite/licenses/`。
- **敏感信息**：扫描待发布源码、嵌套依赖 JAR 与 APK 中的私钥标记、账号令牌、云密钥、口令赋值、带凭据 URL、本机绝对路径、设备序列号、局域网地址与个人邮箱。签名密钥、本机配置、设备日志、截图录像与厂商 ROM 不参与上传。
- **附件**：APK、源码 ZIP、`build-info.json` 与 `SHA256SUMS.txt` 四个附件；发布后核对标签、源码树、附件大小与摘要。

模式扫描不能替代完整安全审计；新增文件和版本需要重新检查。离线回归、安装加载、真实画面、物理触摸与退出恢复分别取证，互不替代。
