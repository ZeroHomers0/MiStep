# Mi Step 使用说明

## 安装和启用

模块包名为 `com.jiusis.mistep`，后续版本沿用此标识。

1. 确认手机已有可用的 Root 和 LSPosed，系统属于本项目当前适配范围。
2. 下载并核对 `MiStep-1.0.4.apk`，安装后在 LSPosed 中启用 **Mi Step**。
3. 推荐选择系统框架 `android`、系统界面 `com.android.systemui`，以及仅用于模块入口的设置 `com.android.settings`。使用小米输入法且需要阻止横屏自动变成悬浮键盘时，可另选 `com.xiaomi.type`；其余普通应用无需勾选。升级不会自动清除 LSPosed 保存的旧勾选，可自行取消多余项。
4. 正常重启手机，让系统进程重新加载模块。

安装后可从 **系统设置 → Mi Step** 打开模块设置页，入口位于「我的设备」下方，无独立桌面图标。界面采用统一的澎湃 OS 4 风格并跟随系统浅色/深色主题。

## 设置页

设置页分为「外观」「窗口与操作」「视频」「锁屏」四组。

| 设置项 | 说明 |
| --- | --- |
| 显示农历 | 在顶部日期下方显示农历；默认开启 |
| 打开 MiStep 的手势 | 「状态栏向内滑」或「底部向外滑」，见下节 |
| 主窗与小窗交换方式 | 「随应用切换位置」或「保持主窗位置」，见下节 |
| 滚动切换小窗 | 上下滑动小窗区域，查看更多小窗 |
| 在最近任务中隐藏小窗应用 | 仅在 MiStep 打开时生效，不会关闭应用 |
| 横屏视频显示位置 | 横屏全屏视频进入时的处理方式，见下节 |
| 解锁后恢复 MiStep | 开启后解锁恢复原有窗口布局；关闭后解锁返回正常全屏界面；默认关闭 |

选择保存在本机，退出或重启后保留。

### 横屏视频显示位置

横屏全屏视频进入时，有三种处理方式：

| 选项 | 行为 |
| --- | --- |
| 顶部播放 | 支持的播放器可在顶部显示视频，主窗和小窗仍可使用；不支持时保留在主窗播放 |
| 主窗内播放（默认） | 视频在主窗内横屏播放，小窗仍可使用 |
| 退出 MiStep，全屏播放 | 退出 MiStep，使用应用原有的全屏播放界面 |

视频接入不改变应用任务本身的大小和位置，只接管播放器已经提供的悬浮视频窗口。设置从下一次进入横屏全屏开始生效。

### 主窗与小窗交换方式

| 模式 | 行为 |
| --- | --- |
| 随应用切换位置（默认） | 小窗中的应用在原侧放大，主窗随之切换位置 |
| 保持主窗位置 | 主窗保持在当前一侧，只交换主窗与小窗中的应用 |

切换从下一次交换主窗与小窗开始生效，不立即移动当前任务。两种模式都使用真实应用任务与动画。

### 打开 MiStep 的手势

| 模式 | 行为 |
| --- | --- |
| 状态栏向内滑（默认） | 从状态栏左侧或右侧向屏幕中间滑动 |
| 底部向外滑 | 从屏幕底部任意位置向左或向右滑动；需先在系统设置中关闭手势提示线 |

沉浸全屏中需先拉出原生状态栏，保持通知与快捷面板未展开，再另起角部手势；未拉出时拒绝。横屏规则相同。

## 打开、交换、退出

- 从**左上角向右**或**右上角向左**滑动呼出工作区。主窗在手势的另一侧，小窗区出现在起始侧。
- 先在主窗打开应用，再点击空小窗格中的 **＋**，将当前主应用收进该格。主窗是桌面时，先打开要收纳的应用；「＋」不打开应用选择器。
- 点击已有小窗可与主窗交换。完整点击、滚动和输入在主窗进行；小窗区用于点按交换和向外滑出。
- 将小窗向所在屏幕外侧滑出，可腾出该格，任务交还系统并留在后台，不主动结束应用。
- 点击标题栏最右侧的放大按钮关闭工作区，恢复普通系统界面。主副交接过程中会暂时保护输入，交接和最终画面提交完成后恢复操作。

## 标题栏与常用应用栏

工作区顶部从上到下是时钟、标题栏和常用应用栏。

| 位置 | 内容 |
| --- | --- |
| 时钟 | 时间、日期，可选农历 |
| 标题栏 | `One Step` 标题 + 四个固定按钮：小窗放在左侧、小窗放在右侧、系统设置、放大为全屏并退出工作区 |
| 常用应用栏 | 固定应用在前，其余按最近使用排列 |

- 长按标题文字可打开顶部横屏任务面。
- 点击常用应用栏中的应用图标，在主窗打开该应用；已在副区时交换已有任务。
- 左右滑动应用栏浏览未露出的图标，松手后支持惯性滚动。
- 长按任意应用图标打开自定义应用选择框，支持搜索、多选；点击「完成」后按选择顺序固定在最前，其余应用继续按常用顺序排列。再次长按可取消勾选，点击「取消」不保存改动。
- 配置按系统用户保存，退出工作区或正常重启后保留。

## 顶部横屏任务面

顶部区域可再保留一个可直接操作的应用，与主窗和三个小窗并存。

- 在顶部空位点「＋」收纳当前主屏应用；窗口内可单指操作、换页和返回。
- 双指在顶部区域上下滑动，可在标题栏面与横屏任务面之间切换；切换使用真实应用画面动画。
- 双指横向滑出可将顶部应用留在后台。
- 应用方向变化不会自动占用顶部。
- 平板横屏有独立竖屏任务区，可双指向主窗滑回原任务，再次收纳时恢复被覆盖的主任务。

## 升级和恢复

1. 升级前先退出工作区，保留当前可用 APK。旧包名版本需先在 LSPosed 中停用，再安装当前包、启用新模块并重新选择作用域；不要同时启用两个模块，正常重启且确认可用后可卸载旧模块。
2. 只有包名和签名均相同的版本才能覆盖升级。1.0.0 的版本码为 `1000000`；改包名后的 1.0.0 需独立安装，后续同包名版本按版本码递增升级。
3. 若系统更新后出现界面或触摸异常，先退出工作区；仍异常时，在 LSPosed 中停用模块并正常重启。无法进入系统时，使用自己所用 Root / LSPosed 方案的恢复方法停用模块。

发行包沿用本项目开发期签名身份；改包名不会迁移旧模块的启用状态、作用域或应用数据。该身份不是应用商店发行证书；自行构建并换用其它密钥签名后，也不能直接覆盖安装同包名现有包。

## 已知边界

1.0.4 最低安装版本为 Android 14 / API 34，适配澎湃 OS 2 / 3 / 4。设备实测范围见[更新日志](更新日志.md)。

平板按呼出时的横竖方向建立工作区，调整时钟、文字、图标和任务区布局。退出后可旋转屏幕再次呼出；工作区内保留当前会话方向。部分机型主窗不缩放、部分图文评论排版、通知拖窗和硬件副屏仍无完整修复或统一验收结论。
